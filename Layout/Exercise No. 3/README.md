# EJERCICIO No. 3 BARRA DE NAVEGACIÓN USANDO FLEXBOX

<p align="justify"> 
El objetivo de éste ejercio era crear una barra de navegación usando flexbox y aplicando los conceptos de media queries.
</p>

## TECNOLOGÍAS UTILIZADAS

El ejercicio está elaborado con CSS, el cual incluye el uso de flexbox y media queries.

### CARACTERÍSTICAS PRINCIPALES Y SOLUCIÓN AL EJERCICIO

<p align="justify"> 
Lo primero que tuve en cuenta para crear la barra de navegación era ver qué cajas existían y cuántas eran necesarias. Entonces, lo primero que maqueté fue el <a href="./index.html">index.html</a>. El título <em>Lemoncode</em> podía estar ligado a una etiqueta <em>h1</em>. En cambio, el contenedor padre para éste caso sería la etiqueta <em></nav class="navbar"></em> con el estilo de <em>display:flexbox</em>, acompañado de sus elementos <em></a> hijos</em>. Para aquellas versiones Mobile (576px y 375px), la clase <em>navbar</em> tendría la dirección como columna y reduje el panel de ancho y largo para obtener el efecto visual de acortamiento del largo de la pantalla y así mismo para las letras y tamaño del título. 
</p>

### DETALLES ADICIONALES 

<p align="justify"> 
Para resoluciones grandes no consideré necesario agregar media queries porque la interfaz no tenía cambios dado que necesitaran ser específicados para otras medidas de pantallas grandes adicionales a las explicadas en el punto anterior. Sin embargo, para versiones Mobile,detalles como los bordes, reducción de pantalla y aumento de la letra sí eran importantes. Además, el comportamiento de la pseudoclase <em>hover</em> establecí un color más oscuro para denotar el cambio de paso basado en su color primario.
</p>
